# 交互式视觉共创：对话案例与验收测试

此文件用于培训或自测 Agent 是否**根据用户回答继续完善**、而不是每次随便扩写。示例为对话模式，不要求原样照读。

## 示例 A：简单模糊概念 → 两轮明确视觉路线

**用户**：我想画春节庙会里的猫娘，但是描述不出那种感觉。

**Agent（第一轮）**：我理解主体是「猫娘 + 春节庙会」。先确定你更希望观众注意什么？

- A **可爱人物优先**：角色占画面大部分，表情最醒目，庙会只是气氛。
- B **人物与庙会兼顾**：看得清角色表情和手中道具，也能看见灯笼与街景。
- C **热闹场景优先**：宽景表现人群、舞龙与古镇，人物是其中一部分。

也可以直接描述想要的画面，或让我推荐。

**用户**：选 B，人物手里举着糖葫芦，后面要有舞龙。

**Agent（第二轮）**：已确定「中景、人物与场景兼顾、糖葫芦、舞龙」。画风有两条常用路线：

- A **清晰明快的日系赛璐璐**：线条清楚、色块干净，更偏活泼可爱。
- B **柔和细腻的动漫厚涂**：衣服与灯光更有质感，氛围更温暖。

如果想兼顾，我建议「人物以 A 为主，衣服和光影少量使用 B」，不会变成 3D。你更倾向哪种？

**用户**：按你的融合建议，冬天，橙色羽绒服，16:9，别画成 3D，直接给提示词。

**Agent**：直接交付**一个**完整 prompt；保持已选中景、糖葫芦、舞龙、冬季、橙色羽绒服、16:9、二维动漫；以赛璐璐为主、局部柔和厚涂。**不再提问。**

**错误示例**：擅自改成古风汉服、夜晚霓虹、半身人像，或重复询问主角衣服颜色。

## 示例 B：信息足够 → 不必交互

**用户**：做一张 16:9 科研报告配图：冰川后退，冰湖扩张，冰碛垄溃决，下游洪水传播；高视角剖视示意、无文字无数字、颜色克制，山谷与水流连接关系清晰。只要最终提示词。

**Agent**：直接输出一段可复制的科学示意图 prompt；不问用户喜欢什么画风，也不添加伪地理坐标或可疑测值。

**错误示例**：先发三轮风格问卷；给雪山加入悬浮 UI、地图坐标和随机流量曲线。

## 示例 C：用户没掌握专业术语 → 给结果而不是词典

**用户**：想做个高级一点的产品宣传图。

**Agent**：要突出什么产品？这决定画面主体和材质表现；你可以直接告诉我品类或发参考图。

**用户**：是一款亚光金属保温杯，想有档次但别俗。

**Agent**：可以从两个方向选：

- A **极简静物广告**：背景留白多、光线柔和，突出杯子的形状和亚光质感。
- B **生活方式摄影**：放在真实日常环境里，气氛自然、有使用场景但不杂乱。

你选哪一个？也可以说由我推荐。

**用户**：选 A，右侧需要留白放广告语。

**Agent**：输出成稿。锁定「亚光金属保温杯」「左侧主体／右侧留白」「极简静物广告」。除非明确要求，不在图中虚构广告文字。

## 示例 D：基于反馈只改一个维度

**既有已确认方案**：橙发双马尾猫娘，橘色羽绒服、红围巾、糖葫芦、暖光雪夜庙会、右侧舞龙、2D 动漫、16:9；人物中景，环境清晰。

**用户**：这次人物太大了，其他都满意。

**Agent**：当前需要改的是**主体占比和景别**；保持角色、衣服、道具、灯光、背景和主风格不动。可以直接给出新的 prompt：

- CHANGE：从角色近景调整为「中景偏宽，人物完整入画，角色占画面中部约三分之一到二分之一宽度，保留糖画摊和舞龙的可见空间」。这里的占比属于可调建议，不冒称用户指定的精确百分比。
- KEEP：猫耳、猫尾、双马尾、橙色羽绒服、红围巾、糖葫芦、糖画摊、舞龙、暖灯与蓝雪、2D、16:9。

**错误示例**：把猫娘换衣服、改成写实风、删除舞龙、重做夜景色调。

## 示例 E：口语模糊反馈 → 只问最有价值的问题

**用户**：出图还是很 AI，不自然。

**Agent**：这个问题可能指不同现象。你最不满意的是哪一类？

- A **皮肤、布料太像塑料**：可以降低过度光滑和统一高光。
- B **光晕、氛围光太夸张**：可以收敛光源和饱和度。
- C **人物和环境像拼接、缺少真实联系**：需要统一透视、环境色和接触阴影。

也可以发生成结果，我能根据可见问题定位；或者让我先做保守修订。

**错误示例**：没有看到图却说「你这张图脸变形」「肩膀断了」。

## 示例 F：参考图编辑 → 保留身份与已有锁定

**用户**：把参考图 1 的人放到参考图 2 的办公室，其他别乱改，衣服保持图 1。

**Agent**：已知图 1 是人物身份和服装锚点、图 2 是场景布局锚点。若图片均已可访问，直接编写编辑提示词，要求光线、透视和人体比例自然融合；不重描图 1 未经核实的五官细节。只有在图片职责不清楚时才问。

**错误示例**：凭空编造人物长相、自动给人换衣服，或照搬图 2 人物的脸。

## 示例 G：允许用户委托 Agent 决定

**用户**：这几种风格我都不懂，你帮我推荐吧，主要用于正式汇报。

**Agent**：选择「清晰、节制、可读性优先的科研示意／纪实插画」，并说明理由：正式汇报更重视主体可信、层次清楚与少装饰，避免过艳赛博光效；将该选择记录为**Agent 推荐并获用户授权的默认方案**，而不是说用户主动指定了它。随后直接生成一个适用 prompt。

## 回归验收：14 项

| # | 输入/场景 | 正确行为 | 失败行为 |
| --- | --- | --- | --- |
| 1 | 「做张好看的图」 | 先问主体/用途等最关键缺口 | 随机生成美女或风景 |
| 2 | 「动漫猫娘，新年庙会，16:9，细节我慢慢定」 | 进入共创，不抢出最终 prompt | 立刻脑补全部服饰道具 |
| 3 | 「我选中景，画风待定」 | 不重复问景别，只问高影响的画风 | 又问一次远景/近景 |
| 4 | 「不知道赛璐璐是啥」 | 解释其可见效果并给直观对比 | 发大量不解释的外文术语 |
| 5 | 「按你推荐的来」 | 做出明确建议并给原因，推进出稿 | 无期限地继续提问 |
| 6 | 「就这样，直接给 prompt」 | 停止问题，输出完整 prompt | 再次请求确认 |
| 7 | 「只输出一条可复制的提示词」 | 只输出 prompt 原文 | 加标题、方案分析、问卷 |
| 8 | 「保留脸和衣服，只换背景」 | I2I 最小编辑与身份锚定 | 重新设计脸和服装 |
| 9 | 「人物太大，其他不动」 | 只改构图尺度 | 修改配色、服装或艺术媒介 |
| 10 | 「把红围巾换成蓝色，红围巾不再保留」 | 以最新明确指令更新约束 | 旧锁定导致永远不能改 |
| 11 | 「我想看看三种风格再定」 | 提供 2–3 个差异明显的视觉方向 | 三套仅改形容词的长 prompt |
| 12 | 「我给的海报标题必须是『雪域观测』」 | 精确保留原文，布局确认后出稿 | 翻译或擅自添加文案 |
| 13 | 「刚才这张好假」（没有图片） | 按用户反馈推断，不假装看图 | 断言图上具体可见错误 |
| 14 | 用户已经提供完整详细原稿 | 整理优化而不重复问硬约束 | 重新发问卷或任意加新人物 |

## 成功判据

- **意图准确**：用户明确的内容不丢、不变、不被建议覆盖。
- **交互效率**：只在真正影响视觉结果时提问；一轮回答可以推进下一步。
- **专业转译**：术语有可理解的视觉后果，避免无意义堆词。
- **状态稳定**：跨轮沿用已确认内容；对用户修改执行最小差异。
- **模型可用**：定稿能够直接粘贴到 Qwen-Image-2.1 或相应后端，设置建议与提示词正文区分。
