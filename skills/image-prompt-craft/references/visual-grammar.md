# 构图、镜头、光照、材质与画幅速查

此文件是**决策字典**，不是需要出现在每条提示词中的项目表。选词要解释画面，不要用摄影术语装饰一张非摄影图。

## 1. 画面信息优先级

1. **主体与动作**：谁、几个人、什么形态、正在做什么。
2. **主次关系**：视觉焦点、次要元素、前中后景、大小比例。
3. **呈现媒介**：照片、2D 平涂、油画、木刻、3D 或示意图。
4. **空间和光线**：镜头视点、阴影、天气、环境层次。
5. **装饰与纹理**：可增质感，不得冲淡前四项。

对单主体插画，前 2 项通常比相机焦距重要；对信息图，文字、区域层级、箭头与图例优于镜头感。

## 2. 构图语法

| 视觉目的 | 实用描述（英文） | 适用提醒 |
| --- | --- | --- |
| 重点集中 | centered composition, clear focal silhouette | 人像、单品、图标 |
| 均衡叙事 | rule-of-thirds framing, subject slightly off-center | 需要展示环境时 |
| 留出标题 | generous negative space on the left/right/top | PPT、封面、海报，不得凭空加文字 |
| 体现广阔 | wide establishing shot, layered landscape depth | 山川、古镇、气象场景 |
| 强调动作 | dynamic diagonal composition, readable gesture and motion direction | 动画、运动、戏剧场景 |
| 建立亲近感 | medium close-up, eye-level viewpoint | 人物与情绪 |
| 强调规模 | elevated viewpoint, long shot, small human scale cues | 城市、地貌、工程 |
| 呈现物体结构 | three-quarter view, unobstructed key features | 产品、装备、建筑 |
| 技术说明 | orthographic projection / isometric view / cutaway diagram | 不与强透视摄影混用 |

**关系词比抽象术语更管用**：`in the lower-left foreground`, `behind the subject`, `along the far-right edge`, `partly framed by lanterns`, `above the snowy ground`。只能写用户规定或为了明确构图所必须的若干关系，避免机械铺满坐标。

## 3. 镜头语言（仅摄影/电影/带明确镜头感的 3D）

| 想要的观感 | 语言 | 注意事项 |
| --- | --- | --- |
| 标准人像 | natural eye-level portrait perspective, gentle background separation | 不必强制镜头型号 |
| 广角环境 | wide-angle environmental view, foreground and distant context | 人脸靠画面边缘会畸变 |
| 长焦压缩 | compressed perspective, softly separated background | 大场景上下文会减少 |
| 低机位有力量 | low camera angle with an intact body silhouette | 避免头身被过度拉长 |
| 高机位俯瞰 | bird's-eye view / elevated three-quarter view | 不等于真实遥感正射影像 |
| 微距细节 | macro close-up, narrow focal plane, tactile detail | 只适用于关注细节 |
| 整幅清晰 | deep depth of field, all major objects legible | 学术图、产品多件陈列 |

避免无缘由的 `85mm f/1.4`、`anamorphic lens`、`film grain`；只有用户有具体摄影意图时才使用。

## 4. 光线设计

每幅图选择一个主光线逻辑，写出“来源 + 方向 + 硬/软 + 对主体影响”。

- 柔和窗光：`soft daylight from the left window, gentle falloff across the face, muted shadows`
- 暖色夜灯：`warm lantern light illuminating the foreground, contrasting with cooler blue ambient snow light`
- 阴天天光：`overcast diffuse light, even soft shadows, subdued specular highlights`
- 产品柔光箱：`broad softbox reflections, controlled edge highlights, soft contact shadows`
- 逆光轮廓：`backlighting defines the silhouette, subtle rim light along hair and shoulders`
- 日落侧光：`low golden-hour sunlight from the right, long coherent shadows`
- 技术示意：`even neutral lighting, high contrast between components and background`（不要舞台化）

**禁止矛盾**：不能同时无解释地要求“均匀无阴影”与“强烈戏剧性硬阴影”；雪夜冷环境与暖灯是合理的局部分工。

## 5. 色彩控制

用主色、辅助色、点缀色来构建视觉逻辑，而不是列出 15 种竞争色。

- 动漫喜庆：`warm orange and festive red as primary colors, gold highlights, deep winter blue background`。
- 科研汇报：`muted blue-gray, ice white, restrained amber hazard accents`；强调色用于信息编码而非随机装饰。
- 商业产品：`neutral off-white backdrop, accurate material color, restrained warm highlights`。
- 复古：`limited ochre, brick red and teal palette, aged-paper undertone`。
- 柔和绘本：`gentle pastel palette, warm cream paper, controlled low-contrast shadows`。

**高饱和与低饱和都不是质量标志**。准确描述需要颜色服务于主体或叙事。

## 6. 材质速写

| 对象 | 可视化材质表达 | 常见错误 |
| --- | --- | --- |
| 羽绒服 | quilted puffed baffles, soft matte nylon sheen, stitching seams, compressed folds at joints | 变成盔甲、瓷器反光 |
| 毛衣/围巾 | visible rib knit, plush yarn fibers, soft drape, woven emblem | 印花像贴纸漂浮 |
| 雪/冰 | powdery snow accumulation, cold blue reflected light, translucent ice edges, localized melt sheen | 全部变成白色塑料 |
| 木质摊位 | weathered wood grain, worn edges, warm lacquer, believable contact shadows | 过度镜面反光 |
| 熬糖/糖画 | translucent amber sugar, warm specular highlights, delicate raised lines, glossy irregular thickness | 糖画变成玻璃钢或黄金雕塑 |
| 古建砖瓦 | aged ceramic roof tiles, snow gathered in creases, weathered painted wood | 古建比例与花纹随意扭曲 |
| 金属 | brushed anisotropic finish, hard but coherent reflections, fine scratches | 任何物品都镀铬 |
| 纸 | fibrous texture, slight edge irregularity, matte pigment absorption | 透明玻璃化 |
| 皮肤 | soft believable shading, natural tonal variation, pose-appropriate highlights | 假塑料皮、过度磨皮 |
| 玻璃 | transmissive material, accurate edge reflections, subtle refraction | 完全不透明或失去厚度 |
| 流体/水 | gravity-consistent flow, reflection/refraction, surface turbulence, wet contact edges | 不真实悬浮和循环水纹 |

只写关键物体的材质。对标志、扁平图、信息图可以不用这些微观质感。

## 7. 图中文字和排版

- 必须原样复制用户要求的字串；必要时用直引号或 Markdown 不改变字串。
- 给每个**必须可读**的文字配置：位置、颜色、字形方向、字体类别（如 bold Chinese calligraphy）、背景对比。
- 如果用户指定一枚“福”字牌，单独指定：`a red diamond-shaped paper charm with the single upright black Chinese character "福"`。
- 不要翻译为 `fortune` 后让模型绘制英文字，也不凭空添加副标题、日期、 logo 或电话。
- 长段中文、密集表格、细微图例或需要字字准确时：建议先生成**无字背景/留白版**，由排版工具叠加最终文字；这比反复增加“文字精准”更可靠。

## 8. 画幅与用途建议

**用户指定画幅时不得覆盖。** 未指定才根据用途建议；画幅属于后端参数，不保证只写在 prompt 里就生效。

| 用途 | 常用画幅候选 |
| --- | --- |
| PPT/演示/网站横幅 | 16:9 |
| 竖版海报/人物全身 | 2:3 或 3:4 |
| 头像、徽章、贴纸、单个商品 | 1:1 |
| 通用横版摄影/风景 | 3:2 |
| 竖屏封面/手机背景 | 9:16 |
| 纸面信息图/报告插页 | 4:3 或 3:4，取决于版式 |

如用户给出 `1920x1080`，按此保留为**要求尺寸**，并抽取比例 `16:9`；别假装后端一定支持该像素数。用户说“4K”表示分辨率/清晰度意向，不代表画幅。

## 9. 科研与专业报告专门约束

- 优先分清“解释机制的示意图”“严格按数据绘图”“新闻摄影式配图”“地图”四种交付。不要把虚构景观包装成实测结果。
- 冰川/冰湖/泥石流/洪水等复合灾害链可以视觉化为从上游到下游的**过程关系**，但地形、行政边界、灾害频率、时间序列、监测站和图例值需要真实来源。
- 用户要“报告风格”通常意味着清晰结构、合理留白、真实物理、不出现过量发光 HUD 或不必要文字。
- 一幅图不必承担整份报告：优先选择一个主过程或一类主信息；复杂信息拆分多图。
- 不能确保精确图中文字、数学符号、坐标和比例尺。可先生成清洁背景，再用矢量制图/程序绘图完成精确部分。
