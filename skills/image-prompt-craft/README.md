# Image Prompt Craft — 交互式视觉创作与生图提示词 Skill

**版本：2.0.0 | 默认目标：本地 Qwen-Image-2.1 | 离线可用 | 无运行依赖**

这个 Skill 不再只是把一句话扩写成几十行术语，而是让 Agent **先帮助用户明确画面，再转成专业提示词**。当用户不熟悉美术、摄影或设计词汇时，Agent 会给出简明的视觉方向和通俗解释，根据用户回复逐步完善。方向已经清楚时则直接生成，不强制问卷。

## v2.0 主要变化

1. **自适应交互**：模糊需求先问最影响结果的问题，给 2–3 个直观选项；复杂任务分轮完善，明确的需求直接出稿。
2. **视觉方案（Visual Brief）**：持续提取主体、用途、风格、构图、画中文字、参考图职责、画幅等；区分用户要求与 Agent 建议。
3. **约束锁定**：角色外貌、服饰、数量、精确文字、位置和用户确认的视觉方向，不因下次优化而自动更改。用户有权随时明确修改旧约束。
4. **专业术语翻译**：提供「看起来是什么效果」而不只是堆专业词。动漫、摄影、国风、插画、产品设计、科学示意图等按场景选择合适术语。
5. **增量修订**：面对“人物太大”“脸不像”“太像 AI 图”等反馈，先区分可见问题与猜测，只改相应维度，保留满意部分。
6. **Qwen-Image-2.1 适配**：确认画面方向以后组织适合文生图（T2I）的成图叙述，或适合图像编辑（I2I）的简短、精准编辑指令。

### 实际对话会怎么进行

**用户**：`画一个春节庙会的猫娘，想要很有氛围但我不知道怎么描述。`

**Agent**：`先确定画面重心：A 人物特写，突出可爱表情；B 人物与庙会街景兼顾；C 大场景，强调舞龙和灯笼。你倾向哪种？`

**用户**：`B。要橙色羽绒服、糖葫芦，偏日漫风。`

**Agent**：`确定中景、橙色羽绒服、糖葫芦。日漫方向你更喜欢 A 色块清晰的赛璐璐，还是 B 光影细腻的厚涂？也可以融合。`

**用户**：`以 A 为主，衣服阴影有一点 B。雪夜，暖灯笼，16:9。直接出提示词。`

**Agent**：立即输出一条完整可复制的提示词，不再询问。人物、配饰和位置等已确认条件保持不变。

如果一开始用户提供完整的画面设定，**不会重复询问这些已知信息**。

## 使用方式

- **共创引导**：`我想生成一张高原雪山科研宣传图，但不懂什么画风合适。请先引导我明确视觉方案，再写 Qwen-Image-2.1 的提示词。`
- **直接出稿**：`直接优化下面这段，不要问我问题，只输出一条提示词：……`
- **方案对比**：`先给我两种不同的视觉路线，讲清楚呈现效果和适用场景，我选完再继续。`
- **持续修改**：`上一版人物太大，其他全部保持。只调整人物与背景的占比。`
- **图像反馈**：`这是实际生成图和上一次 prompt，帮我分析与预期不符的三处，并做最小修订。`
- **参考图编辑**：`图1作为脸部和衣服依据，图2只提供室内背景，人物身份不能改变。`

## 安装

解压后将**完整 `image-prompt-craft` 文件夹**复制到 Agent 的 skills 目录。不要只拷贝 `SKILL.md`，否则交互规则和专业参考库无法按需加载。

**Codex（用户级）**

```bash
mkdir -p ~/.agents/skills
cp -R image-prompt-craft ~/.agents/skills/
```

**Claude Code（用户级）**

```bash
mkdir -p ~/.claude/skills
cp -R image-prompt-craft ~/.claude/skills/
```

**Pi / oh-my-pi（路径视实际版本和扫描配置）**

```bash
mkdir -p ~/.pi/agent/skills
cp -R image-prompt-craft ~/.pi/agent/skills/
```

项目级可复制到 `.agents/skills/`、`.claude/skills/` 或 `.pi/skills/`。若目录里已有旧版，可先备份旧目录，再用新版覆盖；部分客户端需开启新会话或重载才能读取更新。实际路径以客户端当前配置为准。

## 运行边界

- **交互由 Agent 完成**：Skill 不附加 UI 组件、数据库或表单，也不需要用户填写 YAML；通过普通对话确认视觉方向。
- **不会自行生图**：不提供权重、不调用 Qwen 接口、不替换现有 ComfyUI/Diffusers/SGLang 工作流。若希望自动生成并回传图像，需要给 Agent 配备对应调用工具。
- **跨会话记忆**：同一会话内会沿用视觉方案；跨会话想完全保留确认项，可以让 Agent 输出短版视觉方案摘要并复制到新会话。
- **专业限制**：精准地理数据、复杂图表、细小中文文字、同一人物身份的严格一致性，可能需要真实数据绘图、后期排字、参考图或局部编辑，不能靠长提示词保证。
- **模型参数**：不强行写死 CFG、seed、步数、分辨率、`negative_prompt` 等；以本地模型和推理后端支持为准。
- **官方 PE**：如果串接 Qwen 官方提示词增强模型，必须核对改写结果是否仍符合用户已确认的视觉方案，避免两层扩写造成意图漂移。
